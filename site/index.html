Sorgenti dei dati

Dai tuoi conti, ogni giorno.

L'import è incrementale: gira a ogni avvio e una volta al giorno, e scarica solo quello che manca.

  3. Conti bancari via PSD2

    In sviluppo

Tre comandi, poi apri il browser.

Serve Docker. Lo stack avvia PostgreSQL, il backend e l'app.

Terminale 
# 1. Il codice e il file di configurazione
git clone https://github.com/darge98/wallet-insight.git
cd wallet-insight && cp .env.example .env

# 2. La chiave che cifra i token: incollala in ENCRYPTION_KEY dentro .env
openssl rand -base64 32

# 3. Avvio
docker compose up -d --build

L'app risponde su localhost:8081. Al primo accesso crei il profilo e colleghi la sorgente.

Conserva la chiave: se cambia, i token già salvati diventano illeggibili e vanno ricollegati.

Domande frequenti

Quanto costa?

Niente. Il codice è su GitHub con licenza MIT e lo installi dove vuoi. L'unico costo è la macchina su cui gira, anche un mini PC o un NAS.

Quali banche sono supportate?

Oggi tutte quelle che hai già collegato a BudgetBakers Wallet. Con PSD2 la copertura dipenderà dalle banche raggiungibili tramite Enable Banking.

Posso usarlo in più persone?

No, di proposito. Ogni istanza ha un solo profilo. Per una seconda persona si avvia una seconda istanza, con la propria chiave.

Con cosa è fatto?

Angular 22 per l'interfaccia, Spring Boot 4 su Java 25 per il backend, PostgreSQL 17 per i dati. Tutto in container.
